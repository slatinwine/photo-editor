# 照片编辑 · Photo Editor

一个单文件的全功能网页照片编辑器：选图后可加滤镜、调色、裁剪旋转、贴文字、打马赛克、消除瑕疵，最后导出 PNG / JPEG——全程在浏览器本地完成，不上传任何图片。

## ✨ 功能特性

- 滤镜调色：10 款内置滤镜（鲜明 / 自然 / 胶片 / 黑白 / 黑金 / 复古 / 冷调 / 暖阳等），缩略图实时预览
- 参数调整：亮度、对比度、饱和度、色温四轴精细调节
- 裁剪与变换：自由裁剪或按 1:1 / 4:3 / 3:4 / 16:9 / 9:16 比例，支持左旋、右旋、水平 / 垂直翻转
- 文字工具：默认 / 衬线 / 圆润 / 手写四种字体，可拖动摆放
- 画笔与消除：马赛克、模糊笔刷直接涂抹，消除工具可擦除画面局部
- 撤销 / 重做、暂存进度草稿（下次打开可续编辑）、内置示例图片
- 导出 PNG / JPEG，支持的浏览器可一键拷贝到剪贴板

## 🚀 使用方法

用浏览器直接打开 `index.html`，点击「选择照片」（或先用示例图片），在底部工具栏切换六大工具编辑，完成后点「完成」导出。

## 🛠️ 技术栈

- 纯 HTML / CSS / JavaScript 单文件应用
- Canvas 2D 全程本地处理（滤镜、裁剪、画笔、导出均基于 canvas）
- 移动端触控友好，清水混凝土风格 UI
